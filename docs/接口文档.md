## 全局说明（人工补充）

> 本节汇总所有接口通用的约定；各接口的**权限**与**接口描述**已补充在对应接口下。此节由人工对照后端源码补全，Swagger 自动导出无法体现这些信息。

### 基础信息

- **基础路径**：所有接口均以 `/api` 为前缀，本地基础地址为 `http://localhost:8123`（例如登录接口完整地址为 `http://localhost:8123/api/user/login`）。
- **鉴权机制**：基于 **Spring Session + Redis 的 Cookie 会话**，不是 JWT。登录成功后服务端下发会话 Cookie，后续请求需**自动携带 Cookie**。前端跨域调用必须开启 `withCredentials: true`，否则登录态丢失。
- 未登录访问受限接口返回业务码 `40100`；已登录但角色/数据归属不满足返回 `40101`。

### 统一响应结构 BaseResponse&lt;T&gt;

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| code | int | 业务状态码，`0` 表示成功，非 0 见下方错误码表 |
| data | T | 业务数据，随接口不同而变化 |
| message | string | 提示信息，成功时为空串 |

### 错误码表（ErrorCode）

| code | 含义 |
| ---- | ---- |
| 0 | 成功 |
| 40000 | 请求参数错误 |
| 40100 | 未登录 |
| 40101 | 无权限 |
| 40300 | 禁止访问 |
| 40400 | 请求数据不存在 |
| 50000 | 系统内部异常 |
| 50001 | 操作失败 |

### 枚举字典

- **用户角色 userRole**：`user`=普通用户，`admin`=管理员
- **图片审核状态 reviewStatus**：`0`=待审核，`1`=通过，`2`=拒绝
- **空间级别 spaceLevel**：`0`=普通版（≤100 张，≤100MB），`1`=专业版（≤1000 张，≤1000MB），`2`=旗舰版（≤10000 张，≤10000MB）
- **AI 编辑功能 function**：`expand`=扩图，`remove_watermark`=去文字水印，`super_resolution`=图像超分，`colorization`=图像上色，`doodle`=线稿生图，`stylization_all`=全局风格化，`stylization_local`=局部风格化，`description_edit`=指令编辑，`description_edit_with_mask`=局部重绘，`control_cartoon_feature`=参考卡通形象生图。10 个功能均已在配置 `ai-image-edit.allowed-functions` 放开
- **AI 任务状态 taskStatus**：`PENDING`=排队中，`RUNNING`=处理中，`SUCCEEDED`=执行成功，`FAILED`=执行失败，`CANCELED`=已取消，`UNKNOWN`=任务不存在或状态未知
- **AI 编辑额度 user.aiQuota**：持久余额（次数），**不按天重置**。注册与管理员新增用户时由 DDL 默认值发放 `10` 次；用完后前端提示"请联系管理员发放"，管理员在「用户管理 → 编辑用户」里直接改成新的剩余次数（`POST /api/user/update`，仅管理员）。每次 `create_task` 扣 1，任务下发失败或执行失败（`FAILED`/`CANCELED`）自动退回。扣减与退还都走原子 SQL（`aiQuota = aiQuota - 1 ... and aiQuota >= 1`），不做"先查再改"，并发下不会扣成负数

### 分页约定（PageRequest）

- `current` 当前页，默认 `1`；`pageSize` 每页条数，默认 `10`；二者小于 1 时会被重置为默认值。
- `sortField` 排序字段（需在后端白名单内）；`sortOrder` 排序方向，默认 `descend`，可选 `ascend`。
- **特例**：`/api/picture/list/page/vo` 的 `pageSize` **上限为 20**，超过返回 `40000`（防爬虫）。

### 权限标记说明

各接口"**权限**"字段取值：`公开`（无需登录）/ `需登录` / `管理员`（需 admin 角色）/ `需登录+归属校验`（仅数据创建者本人或管理员）。

```javascript
	"message": "ok"
```



**已知限制**：
1. 保存链路复用 `UrlPictureUpload`，其下载步骤（`HttpUtil.downloadFile`）当前**没有超时与响应体大小上限**，属于既有实现，本次未改动。
2. 免费额度（500 张）用尽后自动转按量付费（0.14 元/张）；`user.aiQuota` 余额只是本地护栏（前端可用 `/api/picture/ai/edit/quota` 展示余量，管理员在用户管理里发放），建议同时在百炼控制台开启「用完即停」。
3. 未做并发闸。百炼账号级限制为任务下发 RPS 2、同时处理中任务 2，超限时返回限流错误码，接口会提示「AI 服务繁忙，请稍后重试」。
4. **侵权风险**：官方对 `remove_watermark`（去除他人品牌水印）与 `control_cartoon_feature`（参考受版权保护的卡通形象）明确提示可能构成侵权，需自行确保拥有合法使用权。前端在这两个功能上应给出免责提示。
5. 局部重绘的蒙版以 base64 放在 JSON 请求体里传输，会显著增大请求体积（1024×1024 黑白 PNG 约数百 KB～2MB）；后端只限制 base64 长度上限，**不校验蒙版分辨率是否与原图一致**，不一致会导致结果偏移，需前端出图时保证。
6. **prompt 不允许为空串**（实测）：SDK 的 `ImageSynthesisParam.getInput()` 对 prompt 无判空、`validate()` 是空实现，空串会原样发出，百炼服务端返回 `InvalidParameter: string index out of range`（服务端自身崩溃）。后端已统一兜底：留空先补该功能的默认指令，补完仍为空就在本地拒绝，**任何情况下都不会发出空 prompt**。
7. DashScope SDK 会带入 okhttp/kotlin/rxjava/gson 等传递依赖，已在 `pom.xml` 里把 okhttp3 固定为 4.12.0、kotlin-stdlib 固定为 1.9.25（Spring Boot 2.7.6 默认管理的版本偏低），并排除了 `slf4j-simple`。运行时若出现 `NoSuchMethodError`，优先怀疑这层版本压制。
